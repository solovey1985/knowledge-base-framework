Core concept

Promise

Aliases: JavaScript Promise, async result wrapper

New
Parent: Asynchronous Programming Parent: Event Loop Child: Promise State Related: async/await Related: Microtask Queue
A Promise is an object that represents the eventual completion or failure of an asynchronous operation.

Promises improve readability and composition compared with deeply nested callbacks.

They let asynchronous work be chained, transformed, and handled consistently through success and failure branches.

fetch('/api/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
Think of a Promise as a sealed envelope for a result that will be delivered later.

Lifecycle

Promise State

Pending, fulfilled, rejected

New
Parent: Promise Child: Pending Child: Fulfilled Child: Rejected
A Promise can be pending, fulfilled, or rejected.
A Promise begins as pending and can transition only once to fulfilled or rejected. Once settled, it cannot switch to another state later.
